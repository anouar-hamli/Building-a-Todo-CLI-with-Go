# Go CLI Todo App

A simple command-line Todo application built with Go.

## Features

* Add tasks
* List tasks
* Complete tasks
* Delete tasks

## Tech Stack

* Go
* Go Standard Library

## Getting Started

Clone the repository:

```bash
git clone https://github.com/anouar-hamli/Building-a-Todo-CLI-with-Go.git
cd Building-a-Todo-CLI-with-Go
```

Run the application:

```bash
go run .
```

Build the application:

```bash
go build
```

## Purpose

This project was built to practice Go fundamentals and CLI application development.
